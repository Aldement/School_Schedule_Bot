# 📚 Школьное Расписание Бот для Telegram

Добро пожаловать в **Школьное Расписание Бот**! Этот бот поможет студентам и преподавателям легко и быстро получить доступ к расписанию школьных занятий, выбрав класс и день недели.

## 🚀 Основные Функции

### Для студентов:

1. **Выбор класса**: Студент выбирает свой класс (1-12) для получения расписания.
2. **Выбор варианта класса**: После выбора класса, студент может выбрать подгруппу (А или Б).
3. **Просмотр расписания**:
   - **Расписание на день**: Студент выбирает день недели и получает подробное расписание на этот день.
   - **Расписание на всю неделю**: Студент получает расписание на всю неделю для выбранного класса.

### Для администраторов:

1. **Управление расписанием**: Администратор может обновить расписание для всех классов.
2. **Гибкость настройки**: Легко можно добавить новые классы или изменить существующие расписания.

## 💻 Установка и Запуск

1. **Клонируйте репозиторий**:
    ```bash
    git clone https://github.com/Aldement/School_Schedule_Bot.git
    cd School_Schedule_Bot
    ```

2. **Установите зависимости**:
    Убедитесь, что у вас установлен telebot.
    ```bash
    pip install -r requirements.txt
    ```

3. **Настройте токен**:
    В файле `config.py` вставьте свой Telegram бот токен:
    ```python
    TOKEN = 'your-telegram-bot-token'
    ```

4. **Запустите бота**:
    После настройки, запустите бота:
    ```bash
    python bot.py
    ```
    И откройте бота по ссылке t.me/School_schedule_bot_bot

    Бот будет работать и принимать команды.

## 👨‍💻 Как использовать бот

### Студентам

1. Напишите команду `/start` в чат с ботом. Бот отреагирует приветственным сообщением.
2. Выберите свой класс из предложенного списка.
3. После выбора класса, выберите подгруппу (А или Б).
4. Выберите действие:
   - Для получения расписания на день выберите день недели.
   - Для получения расписания на всю неделю выберите этот вариант.
5. Бот покажет расписание, которое вы выбрали.

### Администраторам

1. **Обновление расписания**: Чтобы обновить расписание, отредактируйте соответствующие данные в коде файла `schedule_data.py`, где прописано расписание. 
2. **Добавление новых классов**: Добавляйте новые записи для других классов в расписание.
3. **Контроль доступа**: Управляйте доступом через настройки токенов и администраторские команды (по желанию).

## 📜 Пример команды

1. Команда `/start`:
   - Приветствие с предложением выбрать класс и подгруппу.
   
2. Выбор дня:
   - Студент может выбрать один из дней недели (Понедельник, Вторник и т.д.), и бот покажет расписание на этот день.

3. Расписание на всю неделю:
   - Студент получит расписание на всю неделю для своего класса.
